# Context Index

Task routes and the derived catalog live here. Follow [shared entry policy](../AGENTS.md), use [File Ownership](ownership.md) to locate a fact's home, and resume through [memory](../memory.md). This page does not restate their instructions.

## Task routing (hand-maintained — edit to fit this project)

| Task | Read, in this order |
|---|---|
| Agent resources, tool adapters or file separation | `ownership.md` → `../.agents/README.md` → `feature-specs/06-single-source.md` |
| CLI/tooling changes | `codebase/map.md` → `code-standards.md` → `testing.md` |
| Build a feature unit | `feature-specs/NN-*.md` → `build-plan.md` (position only) → `architecture.md` invariants → module pages that `brief` returns |
| Fix a bug | `current-issues.md` → module page covering the file (`brief <file>`) → `testing.md` → `decisions.md` (grep the area) |
| UI work | `designs/` → `codebase/map.md` → `code-standards.md` |
| Schema / data change | `architecture.md` invariants → `decisions.md` → `library-docs.md` (ORM) |
| API / route change | `architecture.md` → `codebase/map.md` → `code-standards.md` |
| Add a dependency or integration | `library-docs.md` → `decisions.md` → `testing.md` (record the new decision) |
| Deploy / operate | `workflow-rules.md` → `testing.md` → `library-docs.md` |
| "How does X work?" (question only) | `brief X` → answer from pages. Open code only if a page is stale/low-confidence. File a useful answer back as a page. |
| Unknown area / first time here | `codebase/map.md` → `brief <keywords>` |
| New raw source (PRD, notes, vendor docs) | follow INGEST in the skill's operations reference |

Optional contract, UI and operations pages are listed in the catalog when present; read that entry before following a route.
