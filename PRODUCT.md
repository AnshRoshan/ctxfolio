# Product

## Platform

web

## Users

Developers evaluating persistent, source-backed project memory for coding agents. Confirmed redesign scope: keep the developer-tool product and its current content.

## Product Purpose

Ctxfolio turns repository knowledge into a portable markdown context wiki. Product truth belongs to [the project overview](context/overview.md), [runtime declarations](package.json), and [the website module](context/codebase/modules/website.md), not this design-facing routing record.

## Capabilities and Constraints

The user approved creative control for an end-to-end website redesign on 2026-10-24, preserving product facts, install commands, interactive demos, theme switching, and no-JavaScript support. The existing site is static HTML with React islands and a Vite single-file build. Do not change CLI behavior, package versions, or deployment configuration to achieve the redesign.

## Brand Commitments

Keep the Ctxfolio name and its core proposition: context is compiled, not retrieved. The user requested a beautiful, modern replacement identity and delegated visual selection and implementation without further approval rounds.

## Evidence on Hand

[The website document](web/index.html) contains the current factual copy and source links. [Demo data](web/src/data/transcripts.ts) owns synthetic transcripts and illustrative cost assumptions. [Testing](context/testing.md) owns observed results. No invented testimonials, customer logos, benchmarks, or measured savings.

## Product Principles

- Make the mechanism clear before asking visitors to install.
- Keep examples explicitly synthetic and cost assumptions explicitly illustrative.
- Preserve readable static fallbacks, keyboard access, reduced motion, and both themes.
- Keep detailed technical content available rather than replacing it with promotional claims.

## Accessibility & Inclusion

Preserve the website's existing accessibility contracts from [the website module](context/codebase/modules/website.md): semantic content, WCAG AA text, keyboard operation, static fallbacks, and reduced-motion behavior.

## Open Decisions

None blocking this redesign. Remote deployment and publication are outside its authorization.
